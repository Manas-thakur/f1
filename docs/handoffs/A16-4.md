# A16-4 — weather, altitude, surface, tyre and grip modelling

Status: **complete for this scope.** Real OpenF1 weather tapes are frozen with
hashes, a `TapeEnvironment` satisfies the coordinator's `EnvironmentField`
seam, and the real `Simulator` is slower under a wet, gusty, headwind tape than
under `StaticEnvironment`. No calibration is claimed anywhere.

## Public entry points (for the API / session-factory worker)

```python
from afterlap_core.conditions import load_conditions, environment_for, ConditionsTape, TapeEnvironment

tape: ConditionsTape = load_conditions(conditions_id, paths)
env: TapeEnvironment = environment_for(tape, track, seed=seed)
tape.content_hash
tape.tape_id
env.describes
```

* `load_conditions(conditions_id, paths=None, *, allow_network=True, refresh=False)`
  reads `configs/conditions/<id>.yaml`. `source: synthetic` builds the tape from
  declared constants. `source: openf1` reads the frozen tape at
  `artifacts/conditions/<id>.json` (hash-verified on read, session_key checked
  against the config); if absent it builds from the raw cache
  (`artifacts/tracks/raw/openf1/<sha256>/payload.json`), fetching only when
  `allow_network` is true; otherwise raises `ConditionsUnavailable`
  (a `FileNotFoundError` subclass). It never invents weather.
* `environment_for(tape, track, *, seed=0, rubber_fraction=None)` binds the tape
  to the track frame. If the track exposes `yaw_at(0.0)` (a `CompiledTrackSource`)
  that absolute ENU yaw becomes `heading_offset_rad`; a synthetic sketch has no
  absolute orientation, so the offset is `None`, the wind is projected in the
  engine's relative frame and `describes` says `heading=relative-only`.
* `isinstance(env, EnvironmentField)` is true (runtime-checkable protocol).

Not wired by me (coordinator-owned): `scenario.conditions_id` through the
session factory / `load_bundle`, and recording `tape.content_hash` in the
bundle identity and run record.

## Equations and sources

* **Moist-air density** (`atmosphere.moist_air_density_kgpm3`):
  `rho = p_d/(R_d T) + p_v/(R_v T)`, `p_d = p - p_v`, `p_v = RH * e_s(T)`,
  `R_d = 287.058`, `R_v = 461.495 J/(kg K)`. Ideal-gas limit of Picard, Davis,
  Glaeser, Fujii, "Revised formula for the density of moist air (CIPM-2007)",
  Metrologia 45 (2008) 149-155. Tested against an independent virtual-temperature
  formulation (`T_v = T / (1 - (p_v/p)(1 - R_d/R_v))`) to 1e-9 relative, and a
  hand-computed case (101325 Pa, 20 C, 50 % RH -> 1.1988 kg/m^3).
* **Saturation vapour pressure**: Magnus form, Alduchov and Eskridge (1996),
  J. Appl. Meteor. 35, 601-609: `e_s = 610.94 exp(17.625 t/(t + 243.04))` Pa, t in C.
* **Barometric fallback** (only when pressure is unknown): ISA troposphere,
  ISO 2533:1975 / ICAO Doc 7488, `p = p0 (1 - L h/T0)^(gM/(RL))`, exponent 5.2559.
  Result is labelled `isa_altitude_fallback`; measured pressure always wins.
* **Wind**: ENU frame, heading counter-clockwise from east; meteorological
  direction is "blowing from", clockwise from north (WMO / OpenF1 convention).
  `headwind = -(u cos h + v sin h)`, positive opposing travel; antisymmetric under
  `h -> h + pi` (tested over a grid of directions and headings).
* **Grip** (`grip.py`): `g = clamp(f_wet * f_temp * f_rubber, 0.3, 1.05)`,
  `f_wet = 1 - (1 - 0.55) rain`, plateau `f_temp = 1` on [288.15, 323.15] K with
  quadratic loss `2e-4 /K^2` outside, `f_rubber = 1 + 0.05 r`. Dry reference 1.0.
  All eight coefficients are `Parameter`s with `synthetic_assumption`; the wet
  floor's note cites the road-tyre range (Wallman & Astrom 2001, VTI 911A) as an
  order of magnitude only.
* **Tyres** (`tyres.py`): `peak(compound) * (1 + (wet_adjust - 1) rain) * max(0.7, 1 - k_age * laps)`.
  Entirely synthetic ordering; per-car, so not reachable through `EnvironmentField`.
* **Gusts** (`field.py`): wind speed + `N(0, sigma)` drawn from
  `KeyedRandom(scenario=f"conditions:{tape.content_hash}", seed, bin_width_s)`,
  event type `wind_gust`, clipped at 0. Off unless the YAML enables it. Same seed
  -> identical series; different seed -> different series (tested). This is the
  first exogenous *physical* disturbance reaching the equations of motion (D-06);
  the benchmark's `degenerate_seed_variance` handling should be revisited once a
  scenario names a gusty tape.

## What is synthetic

* Every grip and tyre coefficient (`grip.COEFFICIENTS`, the three tyre tables).
* `static-reference` and `synthetic-wet-gusty` tapes (declared constants).
* The gust sigma and bin width.
* The `altitude_m` metadata on Monza (162 m, approximate public elevation) and
  Mexico City (2285 m, from `RACE_CONDITION_MODEL.md`); Monaco and Spa are left
  `null`. Altitude is never used while pressure is measured.
* Test fixture `openf1_weather_synthetic.json` (hand-authored, labelled).

## What is unavailable (deliberately not fabricated)

* Track-temperature -> grip calibration: none exists; the plateau window is a
  synthetic assumption and says so.
* Tyre calibration: `tyres.calibration_status()` returns `"unavailable"`.
* Rain intensity: OpenF1 gives a 0/1 flag; the model accepts an intensity in
  [0, 1] but real tapes only ever supply 0 or 1.
* Spatial weather: one station per circuit; `s_m` is ignored by `TapeEnvironment`.
* Absolute wind projection on a synthetic sketch track (no yaw): reported as
  `heading=relative-only` in `describes`.
* **Calibration evidence file (D-12)**: I have **no** function that binds a
  weather tape to a circuit and writes `artifacts/tracks/<id>/conditions/calibration.json`.
  Nothing in this scope has calibration evidence to write, so none was written and
  `conditions_calibrated` stays `unknown` in the validator.
* Race-control tapes are structures only; no OpenF1 `/race_control` ingestion and
  no rule semantics (the rules checker owns those).
