## 3. Registry model

* `RegistryEntry`: `track_id` (`^[a-z0-9-]+$`), `display_name`, `country`,
  `official_length_m: LengthProvenance {value, source_url, retrieved_at, sha256, note}`,
  `direction`, `events: [EventEntry {event_id, event_name, round, event_date, race_laps, f1_page}]`,
  `readiness` (default `discovered`, informational only), `notes`.
* `Registry`: `season`, `snapshot_date`, `status`, `calendar_source`, `notes`,
  `entries`; validator rejects duplicate `track_id` and duplicate `event_id`.
* `LengthProvenance.verified` is true only when `value`, `retrieved_at` and
  `sha256` are all present, i.e. the page was actually retrieved and hashed.

Fields the specification snapshot did not carry are `null` in all 23 entries
and are asserted null by `test_shipped_registry_matches_the_specification_snapshot`:
`country`, `direction`, `event_date`. Nothing was invented to fill them.

The registry keeps the specification's track ids verbatim. Note the
specification id for Spa-Francorchamps is **`spa`**, not `spa-francorchamps`;
the manifest directory is therefore `configs/tracks/spa/`. Renaming would be
a registry change the coordinator owns.

## 5. CLI behaviour

* `registry list|show` and `sources fetch` are implemented here.
  `sources fetch --registry-entry <id>` fetches the entry's Formula1.com page
  (priority 5) and, when a manifest exists, its `fia_documents` (priority 1),
  into `RawSourceCache`; a cached copy is returned without network unless
  `--refresh`. A failed retrieval is listed under `failures` and the exit code
  is 1; nothing is substituted.
* `ingest`, `compile`, `validate`, `ingest-fia`, `review-overlay` import their
  module **lazily** with `importlib.import_module` and call exactly the agreed
  signatures:
  `ingest.openf1.ingest_location_session(session_key, track_id, paths, driver_number=None)`,
  `compile.compile_track(manifest_path, paths)`,
  `validate.validate_track(track_id, paths)`,
  `fia_overlay.ingest_fia_document(track_id, event_id, document, paths)`,
  `fia_overlay.review_overlay(track_id, event_id, reviewer, decision, paths)`.
  A missing module, or a module without the agreed function, prints
  `capability not yet available: <module>[.<function>]` and exits **2**.
  Tests force this with `sys.modules[name] = None`, so they keep failing
  correctly even after the modules land. At the time of writing
  `afterlap_core.tracks.compile` is not present and `compile` exits 2 for real.
* `ingest --source` other than `openf1` is refused (exit 1), not stubbed.

## 6. Tests

`tests/tracks/test_registry.py` and `tests/tracks/test_cli.py` open no network
connection: `test_cli.py` monkeypatches `urllib.request.urlopen` to raise in an
autouse fixture, and cache contents are `RawSourceCache.put` fixture bytes
labelled synthetic. They fail on, as required:

* duplicate track ids (`test_duplicate_track_ids_are_rejected`), and duplicate
  event ids across circuits;
* unknown direction, in both the registry and a manifest;
* a manifest referencing a track id not in the registry
  (`test_manifest_for_a_track_not_in_the_registry_is_refused`,
  `test_load_source_manifest_uses_the_registry_under_the_same_paths`,
  `test_sources_fetch_refuses_a_manifest_bound_to_a_foreign_track`);
* CLI faking success when a stage module is missing (five parametrised cases,
  plus a module-without-function case); a present stub is called with the
  agreed signature and its result printed.

Also covered: `official_length_m` cannot be `0`; extra fields rejected;
shipped registry equals the specification snapshot field-for-field with null
where the snapshot had nothing; the six shipped manifests bind to the registry
and share the same page hash as the registry entry.
