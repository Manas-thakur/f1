# Circuit geometry

The 23 JSON files contain circuit artwork imported through [Crowdflow](https://github.com/pulkitxm/crowdflow/tree/c6b8c37c7d82fb48edb2d0f2ccc2fc0d07881791/circuits).

Original geometry: ROY Jules (julesr0y), [f1-circuits-svg](https://github.com/julesr0y/f1-circuits-svg/tree/9c93759b076d1b87eac265a009b21b399253220a), licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). The source revision and input hash are retained in each file.

Changes: metadata joined with the project's length registry; the runtime scales, resamples and lightly smooths coordinates. Artwork is not surveyed geometry. Width, elevation, grip, timing origin and direction remain synthetic modelling assumptions. Registry lengths provide scale only and do not verify the shape or the timing line. No operational circuit certification is implied.
